# NuvexaPro 商店上架验收清单（证据驱动）

当前范围：客户登录、内部账户记录、持仓、历史、自选、客服及注销申请。禁用真实交易，不宣称券商交易、实际证券所有权、资金托管、已成交或收益。

## 工程验证（开发人员）
- [ ] 从最新分支读取完整代码、固定依赖版本并执行自动测试。
- [ ] `cd mobile && npm run check`：TypeScript 和移动单测。
- [ ] `npx expo export --platform android` 和 `--platform ios`：资源/JS 打包。
- [ ] 接入生产 HTTPS API，验证 `/ready` 与真实数据库。
- [ ] 应用内登录/退出、会话失效、两个不同客户的隔离、错误状态、离线恢复均在真实设备测试。
- [ ] 新旧系统账户归属一致，拒绝客户端传入的账户 ID。
- [ ] 验证 `/account-deletion` 在浏览器上可访问，手机无需安装也可发起请求。
- [ ] 验证注销申请不会立即标记为“删除完成”，状态和记录一致。
- [ ] 由运营主体批准并上线真实隐私政策、支持页面和合法数据保留/删除规则。
- [ ] 落实经核实的注销处理人员、处理时限、完成注销/删除程序与可验证记录。
- [ ] 通过 `npm run release:verify` 所有门禁（不代表商店审核通过）。

## 外部账号与上架（需授权所有者）
- [ ] Apple Developer 组织账号、协议、签名、App Store Connect 权限。
- [ ] Google Play 组织账号、应用签名和财务功能声明。
- [ ] 确认应用 ID `com.nuvexapro.globalstock` 永久归属和品牌使用权（正式上架前审核）。
- [ ] Expo 项目归属于合法公司账号；生成合法的 iOS IPA / Android AAB。
- [ ] 法律/持牌机构评估经营范围及目标国家；不应凭“只看账户”逃避金融类审核。
- [ ] 上架材料：隐私政策 URL、技术支持 URL、数据安全/隐私分类、年龄评级、无跟踪声明如属实。
- [ ] 苹果审核账户及安全登录方式；Google 审核访问资料（通过商店安全渠道提供）。
- [ ] 真实设备截图、实际手机安装/启动、关键流程视频与审查记录。
- [ ] TestFlight / Google 内测反馈及审核整改。
- [ ] 批准生产提交、上架地区与发布时间。
