## 清理内容与安全边界
- 账户余额、持仓成本、交易总额、已实现盈亏、资产合计等仅接受后续真实 API 确认的字段，未知为 `—`，避免把 401/503/空响应显示为合法 0；成功返回真实 0 才显示 `0.00`。
- 订单/持仓/自选：服务端记录未知为“数据未同步”，确认返回空数组才显示“暂无…”或 0 条。资金申请与客服不在浏览器伪造实际提交成功。
- 手机端（包括后台客户 App 镜像中的同一逻辑）：默认未授权，**不会凭前端输入完成登录**，不在本地生成买卖订单、KYC、银行、资金和客服业务记录；未知内部资金、成交额、已实现盈亏与持仓成本显示 `—`。真实业务动作仍被阻断。
- 后台保存：没有 Promise 响应确认成功时不再直接向用户提示保存成功。管理员后台真正的 2FA、权限和 CRUD 接入尚未完成。
- `TRADING_ENABLED=false` 保持，没有券商下单调用。撤掉客户页面的开发/接口技术说明文字，保留一般空态和失败反馈；必要合规披露的验收归平台所有者。
- 不在前端重新生成假行情、随机 K 线、模拟资产曲线或假交易历史。

## 三端接口绑定入口（待其他窗口接管，不等于已连通）

| 端 | 模块/实际 DOM 或 JS 入口 | 等待的服务端数据/动作 |
|---|---|---|
| 电脑 | `data-b=cash/total/cost/realized/nord/nhold/nreq/acct/sync`、`#tb-ord`、`#tb-hold`、`#tb-watch`、`#tb-req` | 鉴权后账户快照、持仓、订单、申请、后端已实现盈亏/总资产；账户的未知值必须保持 `null` 或省略而非填 0 |
| 电脑 | `window.CN_FRONT_API_BASE`、`loadData`、`placeOrder`、行情图表 | 需由桥接端根据真实 API 确认路径/字段/权限；订单价由后端用真实有效报价确定，客户端不能自行决定成交价；无有效报价禁下单 |
| 手机 | `data-a=login/tab/open/buy/place/ord/sheet/submit/ksub/bsub/fav/chat/send`（运行时动态渲染） | 真实登录/会话、账户、行情/K线、持仓、订单、资金申请、KYC/银行、客服和幂等/回读；前端当前不会造成功结果 |
| 后台 | `#p-over/#p-cli/#p-appr/#p-fund/#p-cat`（五页），`#m-mir/#m-ap/#m-det/#m-sub/#m-sec/#m-ed/#m-chat/#m-subpass/#m-sublock/#m-com/#m-cf`（十一弹窗） | 复用现有后台十模块服务、MASTER/SUBADMIN 双阶段 2FA、审批、资金/审计与客户数据，先确认权限/接口契约及数据库版本 |
