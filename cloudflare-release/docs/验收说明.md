本轮使用当前发布页面和本机隔离数据库验收。

已验证的流程包括以下内容。

- 桌面与手机注册后自动登录，客户归属对应邀请码的子账户。
- 退出后旧令牌失效，手机刷新回到登录页，找回密码表单及重置码一次性使用。
- 子账户仅访问名下客户，客户 VIP、账户类别、登录与提现权限更改及会话撤销。
- 子账户不能创建下级、上架产品、访问其他子账户客户或审批资金。
- 主账号重置子账户密码、限制与恢复登录，旧会话失效。审计写入失败时密码与会话更新整体回滚。
- 身份与银行卡提交、驳回原因、重新提交、审核通过后重复提交受阻。
- 桌面和手机充值不要求提款密码，提现拒绝错误密码，正确密码可提交，余额不足受阻。
- 主账号初审和终审，重复与并发审批请求只记账一次。
- 两端客服发送到主账号，主账号未读提醒与回复，子账户客服接口受限。
- 总账户按子账户切换资金趋势、客户分组和出入金明细，核对所属范围。
- AAPL、NVDA、SPY 两端六笔买单及后续卖出，余额与持仓对账。
- IPO 申购、配售草稿与复核、未配售返款、重复复核防重及账户隔离。
- 普通基金净值录入与复核、申购、超额赎回拒绝、正常赎回和对账。
- GLD、SLV、USO 历史参考价回放，价格与来源时间留存及订单、余额、持仓对账。
- 手机切页 Logo、实名姓名、审核锁定提示、通知到客服，以及后台分组、镜像和 Esc 返回。

线上复验确认桌面与手机的 TradingView 图表实际绘制。运行时、静态资源、两域名及数据库就绪状态由发布脚本核对。图表截图位于 screenshots。

手机使用 Chrome 移动设备视口。实体 iPhone 的 Safari 与 Android 实机仍需设备验收。普通美股隔离测试采用固定成交价，商品 ETF 回放采用历史样本和固定时钟，实际可取得的价格和时间单列在报价核查记录中。正式普通美股成交报价尚未启用，开通报价权限后需再次进行生产定价验收。
