# 安全加固与验收边界

## 本批次实现
- 发现生产库缺少 auth_attempts，旧 Worker 异常时放行。补充只新增安全计数表的迁移。
- 持久化原子计数，同时按 IP 与账号（认证接口）/ 会话（已登录接口）限制；保存 SHA-256 标识，不存明文账号、IP 或验证码。
- 限流计数异常返回 503；超过次数返回 429 与 Retry-After；敏感认证请求最多 8 KiB；每 5 分钟沿用既有定时任务清理两天前的安全计数。
- 覆盖注册、登录、后台开通/激活、密码找回、后台再验证、基金/IPO/股票/大宗交易、资金申请、提款密码与后台写接口。
- 后台敏感写入要求 5 分钟内的密码+2FA验证。超过时限返回428且不写业务数据；后台安全弹窗验证当前管理员后原请求仅重试一次；取消不执行。不延长原登录会话到期时间。
- 代客只读无需额外验证，代客写入要求近期验证；保留所属客户及角色校验。
- 跨站请求的写操作在业务执行前拒绝；不带 Origin 的 Bearer API 客户端仍兼容。
- 密码校验限制最大 1024 字节；再验证成功或失败写审计，不写密码/OTP。

## 验收
qa/security.cjs 使用本机隔离 PostgreSQL 和 Chrome 验证计数并发、跨IP、变换账号、计数故障、请求体超限、二次验证过期、错误凭证、权限隔离、恢复原操作和取消。
其余原有22组验收同一构建执行。生产仅做新增安全表、只读结构检查及无客户凭证的边界探测，不测试正式客户交易。

## 不能视为已完成
- 浏览器令牌仍存 localStorage；尚未迁移到 HttpOnly Cookie。当前跨站检查不等于完成 Cookie/CSRF 方案。
- CSP仍含 unsafe-inline；需拆分内联脚本/nonce并验证全部图表、镜像后再收紧。
- 未新增 Cloudflare WAF/Access/限流 binding，不能声称边缘WAF已经配置。
- Neon本次读取自动快照 schedule=[]，production main protected=false；这不证明无历史恢复能力，但不能视为已有自动快照和恢复演练。
- 异地加密备份、恢复演练、账务巡检的自动报警通道及外部渗透测试尚未完成。
- 此次没有执行正式客户的安全凭证重置，也没有修改客户资金、订单、持仓。

## 运维
计数表缺失或不可用会阻止受保护的认证/写请求；上线必须先确认迁移完成。遇到503先查数据库和安全计数，不应改回异常放行。
会话5分钟验证窗口、限流阈值见src/security.js。阈值调整必须基于正常流量并重跑安全及业务测试。
生产回滚仅切回上一Worker版本；保留新增计数表即可，不必删表。回滚旧版会恢复原有防护缺口。
