# 免费图文财经阅读接入

来源：FinVibe，https://www.finvibe.blog/news-api 。接口文档明确允许商业使用，卡片保留来源、原文链接和 AI 辅助标识。授权资料核对日期：2026-11-11。

## 业务行为
- /api/news 是仅返回公开文章的 GET 接口，不读取客户数据；上游固定为 FinVibe，不透传登录信息。
- 电脑「行情」→「新闻」显示图文卡片；手机「市场」页直接显示相同内容，无须先打开弹窗。后台镜像共用手机构建。
- 现有 TradingView 市场快讯与个股相关新闻入口保留，财经阅读不冒充个股专属新闻。
- 实测供应商最新文章日期为 2026-10-28，市场分类最新为 2026-10-27；内容属于财经阅读，不声称当天快讯或实时新闻。原始发布日期明确显示，不改写为抓取时间。
- 只使用接口返回的封面；未返回或加载失败时保留封面区域和明确的不可用状态，不捏造图片或自动变成纯文字布局。
- 服务器与浏览器缓存 60 秒，合并并发请求，支持 ETag，异常可重试；后台刷新保留手机新闻节点。
- 拒绝不安全 URL、异常日期、未来日期、重复文章；不渲染供应商 HTML。
