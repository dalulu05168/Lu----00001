1. 桌面行情走势卡新增买入入口。根据当前代码查询已发布大宗产品，进入对应买入确认；没有匹配产品时明确提示未开放，不把指数、外汇或黄金图表误当可交易产品。查询失败显示错误，不伪装成空目录。
