## 本分支修改

1. 首页交易卡片根据 **真实已登录自选列表** 选择展示标的，选择不到时仅使用当前受支持标的列表，不造假市场数据。
2. 点击首页交易卡片时，把它实际指向的 `market/symbol` 映射为交易页选中标的；无法匹配时不切换交易标的。原有行情页“进入交易”继续沿用当前选中的标的。
3. 手机底部首项从“自选”调整为“首页”，与主页的账户摘要/快捷操作内容相符。
4. 增加 Node + JSDOM 回归测试，模拟 **测试环境专用** 已认证会话及受保护 API 响应，验证卡片 MSFT → 交易页 MSFT，不会默默变成默认 AAPL，且导航本身不调用下单 API。

## 保留不变的边界

- 仍复用原登录页的有效 `gsp_token` 会话；`web/mobile-entry.mjs` 仅在原前台显示认证成功的工作台后进行手机转入，不绕开鉴权。
- 独立手机全屏 UI 使用安全区域，**无手机外壳、假状态栏、动态岛或伪造余额/行情**。
- API 继续调用 `/api/account`、`/api/watchlist`、`/api/orders` 等原接口；可信执行报价不可用时订单按钮维持禁用。
- 本分支没有更改线上域名、数据库、金融流水、后台账户、业务权限或真实订单数据。
