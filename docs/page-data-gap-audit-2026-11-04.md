## 剩余缺口与必要输入

| 页面区域 | 当前实际来源 | 补齐需要 |
|---|---|---|
| 最新报价、持仓市值、总资产 | 无可调用报价/汇率源；图表数据位于第三方 iframe | 可用于客户展示的报价与汇率 API，携带市场、币种、时点、延迟、来源和覆盖状态 |
| 已实现收益 | 数据库有内部订单金额，但前台仅最近100条，无成本匹配 | 后台全历史成本匹配方法；明确是否计入手续费/税费，不能仅以最近100条计算终身收益 |
| 日盈亏、月回报 | 无每日净值快照或历史组合估值 | 历史持仓/价格/汇率、现金流及明确收益率口径 |
| 股息 | 无股息入账表/记录 | 实际入账记录及币种；公司宣告派息不等于客户已收到股息 |
| 风险 | 没有风险模型 | 定义可解释指标及真实输入；不能随机填评分 |
| 新闻 | 未配置资讯源 | 可展示的新闻/公告来源，原文链接、发布时间和市场归属 |
| 无TV标识图表 | 免费官方iframe，来源/品牌属于其组件 | 官方允许的去标识方案，或独立图表+独立历史行情数据源；新图表可用前保留原图表 |
| 真实交易/支付/核验 | 没有券商/支付/外部核验 | 不随本轮数据展示接入自动启用，需要独立业务服务与授权 |

## 核实过的外部方案

- TradingView 官方 FAQ 对更改/移除 Logo、名称、署名均引导联系洽谈；当前组件无已公开的去标识开关。https://www.tradingview.com/widget-docs/faq/general/
- TradingView 免费图表股票数据可能延迟且有交易所/标的覆盖限制；不能把 iframe 当成后台报价 API。https://www.tradingview.com/widget-docs/faq/data/
- Twelve Data 免费档注明内部非展示用途；客户展示数据属于业务方案不同能力。不能把免费 key 自动等同于允许对本站客户展示。https://twelvedata.com/pricing-business
- Marketstack 免费档注明非商业用途，商业用途在另一个方案列明。https://marketstack.com/pricing
- 独立图表组件 Chart.js 使用 MIT license，可作为无 TV 界面方向，但它本身不提供股票行情。https://www.chartjs.org/docs/latest/

以上只说明已核实方案，不代表所有可能的数据源都已穷尽，也未订阅或创建任何供应商账号。未发现项目已配置的行情供应商变量或本地密钥文件，仅有 .env.example。
